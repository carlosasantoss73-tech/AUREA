# AUREA — 15-CELL TOOL EXPERT WORKPACK V1

## General theme
Build the reusable Tool Expert Factory and instantiate the first specialist as TikTok Expert.

## Parallel work

| Cell | Mission |
|---|---|
| C01 | Define authoritative knowledge-source contract for tool experts; no local seed becomes institutional authority. |
| C02 | Define specialist authority boundaries and approval model. |
| C03 | Define context-retrieval gate for platform/tool knowledge. |
| C04 | Define runtime contract for natural-language specialist requests. |
| C05 | Generalize the existing platform adapter contract. |
| C06 | Define multi-provider/model execution contract for ChatGPT/Claude/Gemini. |
| C07 | Define deterministic fallback between model/tool providers without inventing connectivity. |
| C08 | Define Tool Expert Factory integration boundary with Nodriza/AUREA. |
| C09 | Define specialist work planner: diagnose → plan → execute → verify. |
| C10 | Define reusable skill/playbook packaging for platform experts. |
| C11 | Define persistence/versioning of expert knowledge, playbooks and learning. |
| C12 | Define A2A/external specialist interface. |
| C13 | Define expert validation suite and regression tests. |
| C14 | Define evidence/audit schema for every specialist action. |
| C15 | Integrate the 14 outputs into one factory contract and product-ready state. |

## Dependency rule
C01→C02→C03→C04 remains sequential where institutional context is involved.

C05-C14 can develop independently where inputs are stable. C15 integrates only after receiving evidence from the parallel cells.

## Three-model execution
For each theme, ChatGPT, Claude and Gemini can receive the same 15-cell objective but must receive distinct work packages or independent angles. They do not become separate authorities. AUREA integrates their outputs using evidence, dependencies and validation criteria.

## First cycle
Theme: TikTok Expert + generic Tool Expert Factory.

The next cycle can use the same 15-cell structure for Gemini/API Expert, then Meta Expert.
